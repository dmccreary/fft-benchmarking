# Image Prompts: Echo the Dolphin

I am about to ask you to generate seven different poses for a book mascot.
Please use a consistent drawing style for all seven images.

Each prompt below is fully self-contained — copy one prompt at a time into
your AI image tool (ChatGPT/DALL-E, Midjourney, Stable Diffusion, etc.).
Recommended output size: 1024x1024, then resize down for web use. After
saving each image, run the padding trimmer described in
[`character-sheet.md`](character-sheet.md) / the project README so the
mascot doesn't render too small inside the 90px admonition boxes.

---
