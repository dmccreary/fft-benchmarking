# Welcome to the FFT Benchmarking Site

Our goal is to get the maximum performance doing FFT on microcontrollers such as the new powerful Raspberry Pi Pico 2 with updated floating point and DSP instructions.

Raspberry Pi Pico 2 comes with the RP2350 Pico 2 ARM Cortex-M33 processor.  It has custom hardware for doing signal processing.  However, very few libraries use this power.
