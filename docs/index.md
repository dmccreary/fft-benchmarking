# Real-Time DSP on a $5 Microcontroller
*Building and Benchmarking the FFT from Scratch*

Our goal is to get the maximum performance doing FFT on low-cost microcontrollers such as 
the powerful Raspberry Pi Pico 2 with updated floating point and DSP instructions.

Raspberry Pi Pico 2 comes with the RP2350 Pico 2 ARM Cortex-M33 processor.  It has custom hardware for doing signal processing.  However, very few libraries use this power.
