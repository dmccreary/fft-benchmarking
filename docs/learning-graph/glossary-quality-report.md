## ISO 11179 Metadata Registry Compliance

Each definition was written to satisfy all five ISO 11179 criteria:

1. **Precision** — defines the concept's specific meaning as used in this course.
2. **Conciseness** — one to two sentence core definition, target 15-50 words.
3. **Distinctiveness** — each definition calls out what separates it from closely related terms in the list (e.g. Bit Depth vs. 6 dB Per Bit Rule, Cortex M0 Plus vs. Cortex M33 Processor).
4. **Non-circularity** — definitions lean on simpler terms or exact cross-referenced glossary terms rather than restating the term itself. An automated substring scan found no true circular definitions (4 initial flags were false positives — e.g. "Radians" naturally uses the word "radians" as a unit name).
5. **Unencumbered by business rules** — definitions describe what each concept *is*, not policies or procedures around it.
