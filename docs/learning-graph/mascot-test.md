# Mascot Style Guide

This page shows all mascot admonition styles for reference. The mascot is
**Echo the Dolphin** — see [`character-sheet.md`](../img/mascot/character-sheet.md)
for the full character design.

!!! mascot-neutral "General Note"
    ![Echo neutral pose](../img/mascot/neutral.png){ class="mascot-admonition-img" }
    This is the neutral style, used for general sidebars or introductions.

!!! mascot-welcome "Welcome!"
    ![Echo waving welcome](../img/mascot/welcome.png){ class="mascot-admonition-img" }
    This is the welcome style, used at chapter openings. "Time to transform!"

!!! mascot-thinking "Key Insight"
    ![Echo thinking](../img/mascot/thinking.png){ class="mascot-admonition-img" }
    This is the thinking style, used for key concepts.

!!! mascot-tip "Helpful Tip"
    ![Echo giving a tip](../img/mascot/tip.png){ class="mascot-admonition-img" }
    This is the tip style, used for hints and advice.

!!! mascot-warning "Watch Out!"
    ![Echo warning](../img/mascot/warning.png){ class="mascot-admonition-img" }
    This is the warning style, used for common mistakes.

!!! mascot-encourage "Keep Going!"
    ![Echo encouraging](../img/mascot/encouraging.png){ class="mascot-admonition-img" }
    This is the encouraging style, used for difficult content.

!!! mascot-celebration "Well Done!"
    ![Echo celebrating](../img/mascot/celebration.png){ class="mascot-admonition-img" }
    This is the celebration style, used for achievements.
